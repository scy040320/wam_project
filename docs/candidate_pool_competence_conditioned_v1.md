# Competence-Conditioned Non-Bimodal Candidate Pool V1

The previous screen used one arbitrary state for many heterogeneous tasks. It
therefore measured frozen-Cosmos task competence more strongly than candidate
selection: almost every task produced either zero or all successful
candidates. This protocol treats a **task-state cell** as the experimental
unit and separates generator competence from selector discrimination.

## Stage C0: clean competence

- Twelve preregistered cached-language cells, including three exposed
  infrastructure sentinels.
- Generate K=4 clean candidates for each cell.
- A cell is eligible for stress testing only when at least 3/4 candidates
  succeed. This filter does not use value, attribution or parsed effects.
- Sentinels are reported but excluded from the count of newly eligible cells.

## Stage C1: fixed stress

- Eligible cells receive the same preregistered 6.9 cm object displacement.
- Generate K=8 candidates from the resulting observation.
- 2..6 successful candidates is the primary non-bimodal stratum; 1 or 7 is a
  boundary stratum; 8/8 with step or WAM-call spread is cost-discriminative.
- 0/8 and homogeneous 8/8 cells are retained as generator-limited or trivial
  evidence; they are never silently removed.

The 6.9 cm intervention is a fixed experimental intensity, not a claim about
typical real-world displacement. Earlier cross-scale runs had parallel
floating nondeterminism and therefore provide only development trends, not a
strict paired calibration. Selector weights are not tuned in C0 or C1.

## Evidence saved per candidate

Each candidate exports target displacement, target-anchor relation before and
after, grasp/release support, trajectory statistics and trajectory risk. Raw
official value, outcome, execution steps and WAM calls remain separate so the
paper can report candidate-pool coverage, conditional selector accuracy,
overall success, harm and execution cost without post-hoc recombination.
