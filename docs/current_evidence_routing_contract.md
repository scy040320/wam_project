## 已核验的缺陷

历史候选效果缓存使用预测图像的质量融合 `*_before` 几何；
由此得到的 `current_grasped_support`、`current_lifted_support` 并不是独立的当前事实。
后一字段还借用候选携带动作。画面重叠、夹爪闭合命令和终态关系均不能证明当前物理抓持、抬升或提前恢复。

## 新的接线

实际当前 RGB / proprio，实体、锚点、使用时刻和哈希
→ 每池共享 current-only 几何代理
→ 独立验证的谓词证书准入
→ 归因更新后、门控前写入对应 belief 事实
→ 原硬门槛
→ 原候选效果特征与冻结效用评分。

- 当前几何是未校准代理；默认事实提取器注册表为空，不生成 TRUE 事实。
- 证书除来源绑定外，还须有独立验证记录，且从实际输入重算谓词；匹配哈希不等于证明物理状态。
- 错实体、错时间、错哈希、GT/模拟器/执行后监督、预测来源均不能准入。
- UNKNOWN 不能抹除旧的可信 FALSE；一个位姿事实不能恢复整条抓持依赖链。
- 新门控副本隔离未来混入的物理证书。原候选预测特征仍用于冻结软评分，模型和尺度不变。
- 既有高置信硬违例不删除，不为保护参考选择添加接受例外。
- 当前 query 的重新渲染与上一块缓存差异只作诊断，不能误当 clean-A/B 物理配对失败。

## 验证与限制

单元测试覆盖来源隔离、候选排列无关的共享当前证据、证据时序、未知保留、假证书拒绝和门槛边界。
原192池重放保留全部失败池、原 train/val 和冻结历史选择身份检查。
候选已有执行结果只代表该候选与原冻结后续策略；退出没有新的执行结果，不能记为失败。
64个已消费场景只可作逐决策诊断；改选后的未来观测不可从旧轨迹推断。

当前不存在已独立验证的部署抓持/抬升/定位事实提取器。这个缺口不能用图像对比度、候选终态或注意力层补成假证书。
因此不能宣称当前事实缺口已补齐，也不能宣布主实验就绪。

## 旧估计语义与参考保护复验

本次仅修实验接口，冻结在线策略、归因器、骨干、残差系数与原结果不变。

1. `WORLD_STATE_CONSISTENT=FALSE`使旧定位估计失效，写为高置信`UNKNOWN`，不冒充当前物理`FALSE`。
2. 已达原谓词硬阈值的旧`FALSE`不被未知抹除。阈值以下的弱`FALSE`不能遮住新的强失效；其旧值、置信度和证据仍保留在历史记录。
3. 历史WORLD/EXEC关键前提未恢复时，新的normal或低视质不能让它自动通过安全使用检查；依赖置信度衰减不等于恢复。新定位成立不恢复抓持和抬升。
4. 实际当前的正证书仍须经过独立验证，并满足该谓词原硬阈值；注册表获批不代表每次输出都足够可靠。
5. 恢复原`select_with_utility`的Pareto切换保护；不再把风险与不确定性清零来绕开它。所有对照使用同一规则，原切换间隔不变。
6. 真正的无学习归因/无DAG对照必须维护自己的历史。共享完整方法旧prior会携带过去的学习归因或依赖传播，不能冒称全链条消融；实验接口拒绝这种输入。

不对历史旧WORLD根`FALSE`做批量语义迁移。历史记录没有独立块时刻字段，不能宣称其时间已严格认证；真实观测否定、旧原始记录与已冻结结果均保留。

原192池复验仅比较一个PRE选择及其记录中的冻结后续执行结果。未执行fallback仍记`unobserved`，不是失败。消融差异不能自动证明学习归因增益，64场景也未重新执行。
